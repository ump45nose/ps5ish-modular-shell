## 全屏候选主题

scripts/prepare-fullscreen.ps1 从本机 Default 生成独立 experimental.pthm，不改已安装主题。它保留全部原生列表与状态槽位，只插入公开的 ModularShell_Browser 控件；注入失败时显示原生列表。

当前只校验 XML、槽位、包结构，尚未启用。必须确认真实注入、缺扩展回退、原生菜单/弹层、SDK 手柄事件与原生导航不会重复处理后，才可作为正式入口。其余 Default 视图仅为系统回退，不代表替换 PS5ish 的主视觉选择。

## 真机执行顺序

1. 正常重启 Playnite，确认扩展菜单与装载日志。先用验证窗口检查真实库和 DS5。
2. 配置一款游戏的本地音乐与预告；确认静音自动预览和预告原声两种模式，关闭自动视频后主动播放仍可用。
3. 在 4K60 / 175% 下测试 DS5 方向、确认、返回、设置、主动预告和断开重连。
4. 用户主动启动所选游戏，检查主页静音、返回同条目、退出后不抢前台。
5. 切到 4K120 重复，记录 GPU、音频输出、输入延迟、画面卡顿与 CPU/GPU 资源；不以离屏渲染耗时替代。
6. 完成全屏候选主题及缺扩展回退后，才标记 B5/对应 AT 用例通过。
