# 开发与自主执行文档

版本：0.7.0；更新日期：2026-09-06。需求基线为 `prd-v0.1.md`，本文件定义实施顺序和证据要求，不改变产品范围。开发按本文件连续推进，无需每完成一个普通代码切片就等待确认。

## 1. 目标与边界

Playnite 负责游戏库、平台接入和启动；Shell.Host 负责协调；主题负责显示；独立插件负责内容与媒体能力。首个正式视觉基线必须来自 PS5ish。实验窗口仅为验证工具，不代替最终 Playnite 全屏整合。

P0 必须有静态安全回退、独立外挂、两套可组合预设、可取消沉浸预览、手柄浏览和真实启动返回。成就、影视和快捷面板均不作为游戏首页的启动依赖。

## 2. 实施结构

| 模块 | 所有权 | 允许依赖 |
| --- | --- | --- |
| Shell.Contracts | 内容引用、展示数据、插件契约 | 基础框架 |
| Shell.Core | 插件生命周期、预览协调、主题组合 | Contracts |
| Shell.Playnite | SDK 映射、启动和会话事件、控件注册 | SDK、Contracts、Core |
| 主题与展示 | 布局、配色、动效、焦点外观 | 通用模型与命令 |
| 独立能力包 | 素材、媒体、成就、影视等 | Contracts 及自身公开依赖 |

禁止核心引用成就/Emby 实现。禁止主题读平台私有数据库或自行定时播放。安装产物、用户配置、手动资产和可清理缓存分离。默认声音模式暂按需求中的氛围预览实现，另一模式保留。

## 3. 阶段及退出条件

### M0-A：契约原型（已完成局部验证）

- 独立示例 DLL、最小清单、静态 WPF 窗口。
- 无插件和坏包回退、选择上下文取消。
- 证据：8 项测试及离屏截图。此状态不代表整个 M0 完成。

### M0-B：Playnite 垂直接入（真实装载延期）

1. B1：记录 SDK/运行时和上游主题基线、许可。
2. B2：实现 GenericPlugin 入口及 PluginUserControl 注册。
3. B3：经公开 SDK 读取真实条目、图片引用、安装状态，主操作交回 Playnite。
4. B4：制作只包含本项目产物的可重复安装包，并验证结构、依赖和加载类型。
5. B5：真实 Playnite 装载、控件插入、空库、返回焦点、卸载回退。
6. B6：拆解 PS5ish 原始布局，明确可选插件字典边界与许可资产范围。

退出条件：真实进程中可以显示与启动库中条目；关闭/卸载后原库不受影响；已验证 SDK 版本表、控件焦点和视觉基线。编译或模拟 API 不替代 B5。

### M0-C：单游戏音视频与实机基准

当前：本地音乐、LibVLC 视频、可靠首帧、声音接管与主动预告已实现。真实 H.264 解码测试通过；真实游戏与手柄/电视闭环仍待完成。M1 的首页/全部游戏/详情/设置及清单 2 有界加载已提前落地。

1. 定义有真实调用方的 AssetProvider/PreviewBackend；本地手动素材优先。
2. 背景立即显示；200 ms 音乐、2.5 s 视频准备由宿主协调。
3. 实现首帧确认、单解码器、取消和声音所有权；提供失败/静态回退。
4. 接入启动、取消、运行和停止事件；游戏运行期间不恢复主页媒体。
5. 真实手柄与目标电视验证，记录缩放、刷新率、GPU、音频输出。

退出条件：一款真实游戏完成背景→音乐→视频→启动→退出返回，100 次快速选择不串台。任何首帧替代方案必须有实测证据。

### M1：P0 最小可用版

当前工程切片：页面/设置、独立素材与视频插件、DS5 SDK 输入、组件字典、设计变量、导航保存已实现；62 项自动断言通过。30 分钟解码资源测试通过，但不能代替电视连续浏览。硬件基线：本机，4K60/120、175%、DS5。验收清单见 acceptance.md。

1. 首页、全部游戏、详情、设置和焦点恢复。
2. layout.ps5ish 分层；两套配色/氛围预设共用布局。
3. 完整清单、能力注册、启停、依赖与诊断；超时失败不阻断基础浏览。
4. 十款 Steam 游戏的许可明确/用户本地素材，主动预告与减少动效设置。
5. 用户配置原子保存、安全启动、手动安装及恢复文档。
6. AT-01～09、AT-12 基础升级和 AT-13；500 条导航、30 分钟资源曲线。

退出条件：上述用例均有证据；硬件未验收时保持“待实机验收”，不宣布可长期替代入口。

### M2：维护和主题扩展

素材锁定覆盖、来源记录、限额缓存、导入导出、配置升级和回滚；增加结构级布局变体。验证更换来源不改主题、换主题不丢用户资产。

0.4.2 已实现独立限额缓存、来源时间记录、引用与锁定保护、配置快照恢复及影院结构；0.5.0 补齐设置页布局选择和独立键鼠维护窗口，涵盖缓存、锁定、索引导入导出和快照。入口与故障边界见 maintenance.md。仍待网络来源适配、完整动效/资产包组合及迁移失败故障矩阵；不因工程切片通过而整体勾选完成。

### M3：Steam 成就

先核验公开数据/事件接口，再做独立奖杯页、去重、隐藏防剧透及唯一通知路径。通过 AT-10，移除后基础浏览无影响。

0.5.0 已实现独立 PA 公开主题控件适配和通用详情扩展页。默认仅展示已解锁内容，明确展开后才请求完整列表；缺 PA 收起入口，返回/切换/卸载移除控件。没有新增通知订阅和音效，当前 PA 唯一输出归属可见。真实 PA、专属奖杯外观和 AT-10 尚未验收，证据与边界见 achievements.md。

### M4：Emby 浏览

独立账号/服务器上下文、继续观看/最近观看/最近添加、海报墙与详情；复用预览协调器。凭证本地保护且日志脱敏，不创建伪游戏。

0.6.0 已使用用户授权账号完成真实登录和只读分区、分页、详情、认证海报验证，提供独立 Emby 插件与原生影视页。令牌使用 Windows CurrentUser DPAPI 并绑定服务器/账号；列表与详情支持离线标记，海报有一天缓存及断网回退。详见 emby.md。共享预览协调器、搜索/筛选与完整影视视觉仍待后续切片；M4 不整体标为完成。M5 正片播放及进度写回未实现。

### M5：Emby 播放

成熟播放后端、音轨字幕能力表、播放开始/进度/停止同步，区分正片与预告。通过 AT-11 播放闭环、断线恢复与冲突规则。

### M6：快捷面板

独立进程、受控本地通信、可重绑定快捷键、输入隔离和焦点恢复；先支持无边框模式，不注入游戏进程。验证故障不会拖垮主页。

## 4. 每个切片的执行循环

1. 阅读当前确切代码和相关需求编号，确定最小可操作交付。
2. 实现代码及关键注释；更改契约时记录版本和消费者。
3. 串行构建；占用时只在原目录顺序重试一次，仍失败则停止构建并报告。
4. 执行与风险有关的回归，查看真实渲染结果。
5. 更新 `implementation.md`：改动、命令、结果、未验证事项与下一切片。
6. 无阻塞时继续下一个切片；遇到账号/设备条件缺失，记录阻塞并先做同阶段不依赖它的工作。

本地可逆工程操作自主执行。不得伪造账号、素材、真机结论；不自动启动用户游戏作为测试。涉及凭证输入或用户真实电视体验时留下具体操作和验收项。安装/升级前保留任务涉及配置的可恢复副本，不改无关资源。

## 5. 证据分级

| 级别 | 证明什么 | 不证明什么 |
| --- | --- | --- |
| 编译 | API 签名及程序集引用可解析 | 真实插件装载、运行正确 |
| 自动测试 | 被测逻辑与失败场景 | 真游戏/手柄/电视兼容 |
| 离屏 WPF | 布局可渲染 | 帧率、焦点输入或全屏效果 |
| 真实 Playnite | 扩展发现、库与生命周期 | 所有硬件/所有游戏 |
| 目标电视验收 | 指定环境的体验和性能 | 未测环境 |

只有退出条件全部满足才完成一个里程碑。失败记录必须保留；不能用样例数据、空壳控件或模拟媒体事件勾选真实集成用例。

## 6. 交付与续作入口

- 构建入口：`build.ps1`；构建目录固定为 `artifacts`。
- 当前状态与证据：`docs/implementation.md`。
- 安装与启动：`README.md`。
- 上游和版本证据：`docs/compatibility.md`（M0-B 建立）。
- 接手时先读本文件和当前状态，从最早未完成的切片继续，不重新搭建已有原型。

长期顺序是 M0→M1→M2→M3→M4→M5→M6；按用户最新决定，当前推进 M2 及后续不依赖设备的工作，待设备到位再补 M0/M1 实机验收。没有获得用户要求定时运行前，不创建后台计划任务。
