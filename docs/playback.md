# M5 正片播放（0.7.0）

进入影视详情，点击“播放 / 续播正片”。开始前重新读取在线进度；离线缓存不能直接开始正片。暂停、前后 30 秒定位、音轨、字幕和停止均为原生按钮。正片与预告使用不同接口，只有正片控制器调用 Emby 播放上报。

## 后端与同步

LocalVideo 独立能力包新增 playback 能力，仍只引用 Contracts；共享同一 LibVLC 引擎与单解码会话。当前为 1280×720 BGR32 软件输出，SDR、内嵌轨道、可定位的普通静态直传片源。HDR、音频透传、外置字幕、直播和服务器转码不属于已验证能力。轨道数包含禁用条目，不等同实际语言数量。

使用 POST PlaybackInfo 建立服务端播放会话，接受普通直传媒体源；媒体源标识可包含下划线，不能与内容路径 ID 共用过窄校验。播放器只获取随机回环地址；代理固定转发一个 HTTPS 媒体，认证头不进入播放器 URL，拒绝重定向、错误路径和多段范围请求。仅监听 127.0.0.1，四个并发连接上限，结束关闭监听。它不是多用户系统的强隔离边界，同一 Windows 账号内的可信代码仍可访问进程资源。

开始上报成功后才打开声音；每 10 秒及用户操作上报进度，停止最终上报。写入串行；在途普通进度不会丢弃最后的暂停状态。失焦暂停正片，重新获得前台不会自动继续。准备期间失焦也保留暂停状态。网络同步失败后暂停，停止后不自动重放旧离线进度；重新进入从服务器读取最新状态。此策略避免离线队列覆盖其他设备，但不承诺不同设备同时播放同一条目的服务端冲突合并。

## 真实验证

2026-09-06 用户授权使用“电视剧-下载”内《神雕侠侣》。定位分区 136459、剧集 137017、单集 137710（第 1 集）。测试前进度 0、未看完。

- 初次静音播放约 5 秒：真实首帧、播放开始、暂停、停止均成功；服务器把片头短进度归零，没有把此轮计为续播持久化通过。
- 显式定位 180 秒后短播：停止后回读 1853530000 ticks，约 3:05.353。
- 再次打开实际从保存位置续播：停止后回读 1906920000 ticks，约 3:10.692；仍未看完。此为测试留下的用户观看进度，没有恢复成未观看状态。
- 当前条目返回 3 个音轨条目、4 个字幕条目；已查看实际解码画面。测试静音，不证明实际电视听感、所有轨道的同步或输出设备兼容。

日志：artifacts/emby-playback-live.log、emby-playback-seek-live.log、emby-playback-resume-live.log。截图仅在本机，不随安装包分发。13 项隔离协议测试、真实本地 H.264 定位/音轨测试纳入默认构建；默认构建不会执行真实服务器写入。
