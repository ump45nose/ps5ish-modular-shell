# M6 独立快捷面板（0.7.0）

Playnite 主菜单 → Modular Shell → 启动独立快捷面板。默认 Ctrl+Alt+Space 呼出/收起，也可选择 Ctrl+Alt+F8/F9/F10。仅显式启动后驻留，未注册系统自启动或计划任务。点击“退出面板”释放快捷键；再次使用从主菜单启动。

提供当前游戏/会话状态、手动追踪目标、个人笔记和用户填写的 HTTPS 攻略链接。追踪目标明确标为个人记录，不假装来自成就系统。数据保存在 SDK 用户目录的 quick-panel 下，按游戏 GUID 隔离，临时写入后原子替换并保留 .bak。配置恢复工具当前不收集该目录，备份个人笔记时需单独保留该目录。

## 进程和输入边界

Shell.QuickPanel.exe 是独立 WPF 进程，不注入游戏，不暂停游戏，不转发游戏输入。命名管道只接受 snapshot 读取，限定当前 Windows 用户，双方核对对端 PID；无远程监听、任意命令执行或游戏启动命令。

面板呼出时保存前台窗口并要求成功获得焦点；失败则收起。收起前若面板仍持有前台，才恢复原窗口，避免用户切换应用后抢焦点。键盘 Tab 在面板内循环，Esc 保存并返回。热键冲突保留可诊断状态，恢复旧热键失败不会假称成功。

无边框窗口是目标场景。隔离基于正常前台输入路由；仍在后台接收 Raw Input、手柄或全局钩子的游戏可能继续收到输入，不承诺全局阻断。未实现游戏内手柄快捷组合。独占全屏和具体游戏的输入/焦点体验须实机验收。

## 退出和故障

宿主断开后子进程退出并释放快捷键。笔记保存失败会保留窗口和编辑内容，同时释放热键，避免为清理进程而丢笔记。宿主不会强杀用户进程。面板崩溃/管道异常不传播到主页，重新从菜单启动可建立新通道。

实际子进程测试已完成双端 PID 验证、连续快照、上下文变化及断开后退出；另验证个人笔记保存和 WPF 离屏布局。日志 artifacts/quick-panel-integration.log，截图 artifacts/quick-panel.png。测试使用明确标注的模拟游戏上下文，没有启动用户游戏、注入按键或测试真实游戏的后台输入。

M6 工程首版已交付，真实无边框游戏的快捷键、输入隔离、焦点恢复及物理手柄仍未通过验收，不整体标记里程碑完成。
