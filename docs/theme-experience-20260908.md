# 2026-09-08 PS5 主题动效与布局交付

本轮按用户提供的 PS5 奖杯横卡、密集方形游戏库参考重新实现。已经构建、备份部署并正常重启 Playnite；工程与本机页面验证通过，目标电视的动态观感、实际听感及实体 DS5 验收仍未完成，不标记整体 M6 完成或像素级复刻完成。

## 改动与配置

入口：右上设置 → 滚动到底 → **PS5 主题 · 动效与布局**。独立配置存于扩展 userdata/theme-experience.json，采用原子保存，旧安装无文件时使用默认值。

| 模块 | 本轮行为与可配置项 |
| --- | --- |
| 启屏 | 默认光尘、柔光、标题淡入与首页淡出衔接；可关闭粒子。已有“启屏动画 / 主题曲”入口继续支持本地视频和音乐 |
| 焦点 | 选中边框颜色缓慢呼吸、封面轻微缩放；可关闭，卡片切换时长可调 0–1000 ms，默认 260 ms |
| 背景 | 交叉淡入、轻移淡入、直接切换；时长 0–1500 ms，默认 650 ms。保持等比完整显示，不以裁切或放大制造转场 |
| 首页奖杯 | 恢复完成率、已解锁/总数与细进度线；可隐藏摘要，白金微光与一次扫光可关闭 |
| 奖杯详情 | 四色计数、横向虚拟化奖杯卡、排序、隐藏内容开关、独立完整描述区；可选择纵向卡片排列及隐藏四色计数 |
| 游戏库 | 默认六列紧密方形封面，可选五至八列；标题和平台默认隐藏，可重新显示 |
| 游戏库图标 | 收藏书脊与叠卡两种矢量图标 |
| 操作声音 | 原创生成的开机、游戏切换、焦点移动、确认、返回五类短音效；每类可选择本地文件或恢复默认，开关与音量沿用界面音效设置 |

减少动效覆盖新增动画。音效文件是短提示用途：开机播放会话上限约 3.3 秒，其余约 0.65 秒；长音频不能作为完整曲目使用。自选启屏视频使用片源声音，不叠加默认开机声或粒子。音乐仍通过独立主题曲入口配置。

## 奖杯与滚动修复

原详情直接嵌入 PA 默认表格，表格尺寸与主题详情视口不匹配，且视觉沿用 PA 表格。本轮替换为主题自有卡片列表：给列表明确可用视口，虚拟化并在选中变化时 ScrollIntoView；底部描述独立滚动。普通游戏详情简介也增加滚动容器。

数据继续读取 PA 公开上下文，按当前游戏 ID 匹配。四色汇总使用提供者数值，不重新设定稀有度阈值。白金保持有效 Capstone 优先、无 Capstone 时使用 IsCompleted 的既定规则。首页移除三色数量，但保留白金装饰；详情展示金银铜白金数量。隐藏且未解锁的成就默认不向展示模型传递真实名称、描述或图标。没有新增解锁通知，也不写回 PA 数据。

公开接口参考：[Legacy Bindings](https://github.com/justin-delano/PlayniteAchievements/wiki/Legacy-Bindings)、[Modern Bindings](https://github.com/justin-delano/PlayniteAchievements/wiki/Modern-Bindings)。
