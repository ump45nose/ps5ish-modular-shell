# 影视服务入口与全屏网页（2026-09-11）

用户需求：影视先选择不同服务，Emby 为第一个样例，服务内部直接全屏显示原网页并适配手柄。

## 实现

- 影视入口改为服务目录。`ModuleLoader.GetHubProviders()` 支持多个声明 `hubView` 的插件；其他能力继续单提供者隔离，旧 `GetCapability<IHubViewProvider>()` 保持首个服务兼容。
- 服务卡由 `MediaHubView` 呈现，复用 `HomeCarouselPanel` 的固定选中位置、放大和横向移动；主题新增 `MediaServiceStyle` / `MediaServiceTemplate`，使用透明渐变焦点框，旧组件包自动补齐槽位。
- Emby 的 `CreateView()` 改为 `WebLibrary`。保留旧 API 浏览/播放实现及用户配置，不再作为当前默认入口。网页独立开关保存在 `emby/web-disabled`。
- WebView2 直接访问用户指定 HTTPS 地址。网页层位于游戏 Viewbox 外，以实际客户区显示，不保留宿主标题栏或页面边距。
- 登录、海报、搜索、播放和进度均由原 Emby Web 负责。只注入焦点样式、空间导航与按需手柄键盘，不改服务端，不转换已有 REST 令牌。浏览器会话存放在 SDK 用户目录 `emby/web-profile`，不进入安装包。
- WebView2 SDK 固定 `1.0.3650.58`，NuGet SHA-256 固定校验；包内包含 Core/WPF 程序集、x86/x64 loader 和许可，使用本机 Evergreen Runtime。
- 关闭页面销毁浏览器并恢复服务焦点；失去前台暂停网页媒体，不自动恢复。SDK loader 仅首次配置，避免再次进入抛出 InvalidOperationException。

## 操作

| 操作 | 手柄 |
| --- | --- |
| 移动焦点 | 方向键 / 左摇杆 |
| 点击、打开文字键盘 | × / A |
| 关闭键盘、网页后退 | ○ / B |
| 暂停 / 继续网页视频 | □ / X |
| 返回影视服务入口 | Options / Start / Y；键盘 F10 |

文字键盘支持英文字母、数字及常用符号；中文可用实体键盘输入。网页上的字幕、音轨和播放设置继续使用 Emby 原生控件。本轮未宣称所有输入法、选择控件和第三方页面都已兼容。

## 二次进入手柄失效修复

Playnite 10.56 的 GameController.SendControllerInput 在 StandardProcessingEnabled 且 PrimaryKeyboardDevice.ActiveSource 为空时提前返回，连 SDK ButtonChanged 都不发送。WebView2 的原生窗口取得焦点后可触发此路径，运行日志也显示第二次进入的 A 之后没有新的 SDK 按键事件。

本地网页桥现在保存浏览器原生 Gamepad 读取方法，网页有焦点时按标准映射直接接收手柄；SDK 继续作为备用路径。两路输入通过原生接管时限及跨源短时去重避免重复点击，Options 经限定同源的固定消息退出页面。Emby 自身轮询仍禁用，页面布局不改变。

x86 与 x64 各 19 项通过：同一 profile 连续三次开关，第二、第三次均验证无 SDK 回调下方向与 Options 可用，以及双路确认仅一次。原生输入测试使用模拟标准 Gamepad 数据驱动实际 WebView2 脚本；物理 DS5 的二次进入效果仍待用户验证。
